## 🎮 すぐに遊ぶ (How to Play)

### 1. ローカルで遊ぶ
特別なサーバーやインストールは一切不要です。
1. このリポジトリをダウンロード（または `git clone`）
2. `index.html` をお好みのブラウザ（Google Chrome, Edge, Arc などの Chromium 系推奨）でダブルクリックして開くだけ！
3. 画面をクリックすると、BGMおよび立体音響が有効化されます。

### 2. GitHub Pages でオンライン公開する場合
1. リポジトリの **Settings** > **Pages** を開く
2. **Branch** を `main`、フォルダを `/ (root)` に指定して保存
3. 発行されたURLにアクセスするだけで、世界中どこからでもブラウザでプレイ可能です！

## 🌟 主なゲームモード

### 🪂 バトルロワイヤル (PvP / 24人対戦)
- **参加人数:** 24名（プレイヤー 1名 ＋ 自律思考型AI 23体）
- 空輸機からのスカイダイビング＆パラシュート降下からスタート。
- 武器、防具、回復アイテムを現地調達しながら、刻一刻と縮小する電磁ストームから逃れ、最後の1人（Winner Winner）を目指します。
- **高度なAIボット:** アイテムを漁り、遮蔽物を利用し、建物のドア開閉や階段昇降を行いながらプレイヤーと銃撃戦を繰り広げます。

### 🧟 サバイバル (PvE / 感染者の夜)
- 血の月（Blood Moon）が夜空に浮かぶ廃墟で、全10ウェーブにわたる感染者の襲来を耐え抜くPvEモード。
- **敵タイプ:**
  - **グール:** 数で圧倒する標準的な感染者
  - **クローラー:** 地を這い、素早い動きで死角を突く異形
  - **ブルート:** 圧倒的な耐久力と突進力を持つ巨漢
  - **アボミネーション:** 最終ウェーブに君臨する巨大ボス
- ウェーブ間には赤い発煙筒とともに強力な補給物資が投下されます。

### 🎯 射撃訓練場 (Training Ground)
- 全7種類の武器を自由に試射できるサンドボックスエリア。
- 鉄板ターゲット、ポップアップ標的、移動標的、ゴア表現検証用ダミーを設置。
- キー操作で瞬時に敵ボット（`[B]`）やモンスター（`[N]`）を召喚、全消去（`[K]`）が可能。

## 🗺️ 多彩な3つの戦場マップ

| マップ名 | 環境・特徴 | 戦闘スタイル |
| :--- | :--- | :--- |
| **ダストバレー** (Dust Valley) | 乾いた岩山と砂漠の渓谷。軍事基地、給油所、点在する廃屋 | 開けた視界での長距離狙撃、起伏を利用した立ち回り |
| **ブラックウッド** (Blackwood) | 濃霧が立ち込める森林と湖沼。ロッジ、監視塔、廃教会 | 樹木や霧に紛れた近接奇襲、湖を泳いで横断する強襲 |
| **ネオンルイン** (Neon Ruins) | 雨煙る夜の廃都市。高層ビル群、ネオンサイン、入り組んだ路地 | 立体的な高低差、室内クリアリング、激しい市街戦 |

## ⚡ 注目システム ＆ こだわり機能

- **高度なパルクール・アクション:**
  - 窓枠や低いフェンスに向かってジャンプすると、スムーズに乗り越え（Vaulting）を行います。
  - 高所から飛び降りても、着地時に前転（受身）を行うことで落下ダメージを大幅に軽減。
  - 水場は泳ぎで渡ることが可能（`Shift` で高速スイミング）。
- **過激なゴア ＆ 部位破壊表現:**
  - ヘッドショット時の頭部破裂、散弾や爆発による四肢切断、飛び散る肉片、壁や床に付着する血痕デカール。
  - 演出は設定から「オフ / 標準 / 過激」をいつでも変更可能。
- **視点切り替え & 酔い防止機能:**
  - `V` キーで一人称視点（FPS）と肩越し三人称視点（TPS）をシームレスに切り替え。
  - 画面シェイク・頭の揺れを0にする機能や、FOV（視野角）の調整に対応。
- **完全コード生成アセット (Zero Asset Dependencies):**
  - **音響:** 7種の銃声、弾丸飛翔音、薬莢の落下音、足音、水しぶき、BGMにいたるまで、すべて **Web Audio API によるプロシージャル合成音**。
  - **テクスチャ:** ネオン看板、コンクリート、木目、レンガなどのマテリアルも Canvas 2D で動的生成。
- **管理者チートモード (Sandbox):**
  - メニューでパスワード `admin` を入力すると解放。
  - 神モード（無敵）、弾薬無限、炸裂弾、反動ゼロ、敵位置透視（ウォールハック）、敵AI完全停止、一括殲滅（`[X]`）、照準先へのテレポート（`[T]`）などを自由に発動可能。

## 🛠️ 開発・ビルド環境 (Development)

ソースコードは `src/` 配下に機能別にクリーンにモジュール分割されています。

### 必要要件
- Node.js (v18 以上推奨)

### セットアップ & ビルド
```bash
# 依存関係のインストール (esbuild & Three.js)
npm install

# 変更後の game.js をビルド
npm run build

# 配布用パッケージ (dist/ フォルダ) の作成
npm run build:dist

# ローカルサーバーの起動 (動作確認)
npm run dev
```

### ディレクトリ構成
```text
LASTFALL/
├── index.html         # ゲームUI・HUD・モーダル画面
├── game.js            # 配布用バンドル済みゲーム本体 (単体動作可能)
├── build.sh           # ビルドシェルスクリプト
├── package.json       # プロジェクト設定・npmスクリプト
├── LICENSE            # MITライセンス
├── README.md          # 本ドキュメント
└── src/               # ソースコード (ES Modules)
    ├── main.js        # エントリーポイント・メインループ・UIイベント
    ├── engine.js      # Three.js レンダラー・ライティング・ポストプロセス
    ├── audio.js       # Web Audio API シンセ音・BGM・立体音響生成
    ├── weapons.js     # 武器パラメータ・ビューモデル挙動
    ├── combat.js      # 射撃判定・弾道・ダメージ・グレネード
    ├── humanoid.js    # プレイヤー＆ボットモデル・IK・ラグドール
    ├── player.js      # プレイヤー入力・パルクール・移動・カメラ制御
    ├── ai.js          # ボット＆モンスターの知能・索敵・行動ツリー
    ├── modes.js       # バトロワ・サバイバル・訓練場ロジック
    ├── maps.js        # 3種類のマップ生成 (地形・植生・オブジェクト)
    ├── builder.js     # 建物・障害物・階段・プロップのプロシージャル生成
    ├── textures.js    # Canvasを用いたプロシージャルテクスチャ生成
    ├── vfx.js         # ゴア・切断・爆発・マズルフラッシュ・パーティクル
    ├── hud.js         # ミニマップ・HUD・レティクル描画
    ├── zone.js        # 電磁ストーム収縮処理
    ├── loot.js        # アイテムスポーン・補給物資
    └── actor.js       # アクター基底クラス・アニメーション
```
